## Remaining limits

- **General MVR/PSR:** an earlier selective conversion changed a shared DmxCurves fingerprint. A faithful historical backup reproduced the original baseline; algorithm-only controls did not explain the difference. Prepare preserved the exact fingerprint input stream. The first deeply nested raw capture was truncated and its full-tree claim was corrected; complete after-Prepare controls were then captured. The new reproduction stopped before Finish, so it does not resolve the earlier general-PSR negative.
- **Focus and colour:** synthetic calibration and programmer readback are distinct from measured optical calibration, photometry, continuous trajectory clearance and native shadows. CMY/wheel/CCT/white routes require appropriate explicit mappings and native/physical qualification.
- **Controls:** supported Normal attribute-control primitives passed; the tested Preview context lacked the expected PresetBar. Physical control surfaces and unsupported functions remain unqualified.
- **Deployment:** local Node source/build, imported Lua, already-running clients and private instance copies have separate identities. Installing source does not hot-reload a console plugin or another author's active client.
