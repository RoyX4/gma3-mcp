## Limitations

Physical output, calibrated optics and other operating systems remain unmeasured. A loaded show carries its
own imported copy of the plugin, so each console runs 0.51.0 only after the plugin is replaced in its show.
Before that, the server falls back to individual commands where the bridge lacks an op.
